# To-do List com React + Recoil

Aplicação de gerenciamento de tarefas com estado global usando **Recoil**.

## Funcionalidades

- Adicionar tarefas.
- Listar tarefas.
- Marcar/desmarcar tarefas como concluídas.
- Remover tarefas.
- Filtrar por:
  - Todas
  - Concluídas
  - Pendentes

## Estrutura

- `src/components`: componentes da interface.
- `src/atoms`: átomos do Recoil.
- `src/selectors`: seletores do Recoil.

## Como executar

```bash
npm install
npm run dev
```
